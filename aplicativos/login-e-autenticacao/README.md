# Tela de Login — Sistema Interno

A tela de login foi remodelada para a identidade visual preta, laranja e branca.

## Imagem de fundo

A interface referencia a imagem:

`/aplicativos/imagens/time-ir.png`

Coloque/maintenha o arquivo `time-ir.png` nessa pasta do projeto para que a foto seja exibida como fundo da área esquerda.

A logo exibida na tela é a existente em:

`/aplicativos/imagens/logo-login.png`

## Elementos removidos

- Caminhão ilustrativo da referência.
- Frase promocional “Mais controle. Mais agilidade. Melhores resultados.”.
- Versão do sistema abaixo do botão Entrar.
- Efeito decorativo no canto superior esquerdo.
- Conteúdo genérico no lugar dos módulos do portal.
